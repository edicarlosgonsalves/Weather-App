# 🌦️ Weather App PRO

Aplicativo de previsão do tempo desenvolvido com **HTML, CSS e JavaScript**, com uma interface moderna e intuitiva para consultar informações meteorológicas.

## 📌 Sobre o projeto

O Weather App PRO foi criado para praticar e aprimorar meus conhecimentos em desenvolvimento web, principalmente manipulação do DOM, consumo de APIs e lógica de programação com JavaScript.

O projeto possui uma interface com fundo em degradê azul, cartões translúcidos e layout pensado para facilitar a visualização das informações.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização, cores, layout e responsividade.
- **JavaScript** — lógica da aplicação e interação com o usuário.
- **API meteorológica** — para consultar informações do clima, conforme a configuração do projeto.

## ✨ Funcionalidades

- Consulta de informações meteorológicas.
- Integração com API de clima.
- Interface visual moderna.
- Interação dinâmica com JavaScript.

*As funcionalidades disponíveis dependem da implementação atual e da configuração da API.*

## 💻 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Se necessário, configure uma chave válida da API meteorológica conforme as instruções do serviço utilizado.

## 📚 Objetivo

Este projeto faz parte do meu aprendizado independente em desenvolvimento web. Foi desenvolvido para praticar HTML, CSS e JavaScript, melhorar minha lógica de programação e aprender a integrar serviços externos por meio de APIs.
